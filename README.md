# Beginnings & Endings

A musical pyramid scheme for the launch of Beginnings & Endings, the album by my band Brightly. It was an application to track and share music on a world map: you shared the single, "Preflight Nerves", in exchange for a copy of the album.

Status: archived. Made in 2013, not maintained. This is the original source, a very old Rails 3.2 app written by someone who wasn't 100% sure what they were doing, so proceed with caution. It's provided as is, for archival purposes, and would need significant work to run again. What's deployed today is a single page explaining that the project has been retired. That page lives in [superhighfives/beginnings-and-endings](https://github.com/superhighfives/beginnings-and-endings).

Live: https://beginnings.wewerebrightly.com/
